# Security Policy

## Scope

The Bonds Coin public-testnet reference is experimental, no-value software. It does not manage customer funds, private keys, BONDS issuance, custody, payments, trading, or redemption. Findings related to the `bondscoin-testnet/` source, build process, local demonstration, or documentation are in scope for responsible disclosure.

## Reporting a vulnerability

Please do **not** publish proof-of-concept exploit details before maintainers have had a reasonable opportunity to assess and remediate the issue. Report the affected revision, a minimal reproduction, impact assessment, environmental assumptions, and any suggested mitigation through the repository’s private security-advisory mechanism.

This repository does not promise a bounty, production uptime, or a remediation timeline. A production program must establish a monitored reporting address, safe-harbor language, ownership, severity taxonomy, response service levels, and coordinated-disclosure procedure before public network operation.

## Security boundary

No report should assume that the reference node is suitable for funds, customers, or a live asset. The required production gates are documented in [THREAT_MODEL.md](./THREAT_MODEL.md) and [../BONDS_COIN_PRODUCTION_READINESS.md](../BONDS_COIN_PRODUCTION_READINESS.md).
